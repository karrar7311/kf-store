# K&F homepage — scroll upgrade brief

**Self-authored under delegation.** The owner asked to continue editing the existing K&F site (not rebuild it) and did not answer the interview. Decisions below are authored, not quoted. Existing shop, cart, fitting room, GitHub Pages deploy and photography stay untouched.

## Topics
0. **What / who / action.** K&F is a premium, young, modern fashion brand. The visitor should believe it is a serious international label with real construction. Action: *Shop* (add to bag / try on).
1. **Vibe.** Dark, tailored, quiet-loud, exact. Refs: a runway film shot in near-darkness; a tailor's atelier; a technical-garment spec sheet.
2. **Journey.** Hero (recognition) → manifesto (tension) → **The Assembly** (turn + peak) → editorial spreads → collections → accessories → 3D studio → fitting room → campaign → runway → lookbook → essentials.
3. **Energy.** Calm manifesto → intense Assembly (largest span, 520vh) → calm editorial → rising through runway.
4. **Feeling.** Wonder at the Assembly: the garment builds itself from its real parts. Trust after it completes.
5. **Signature move.** *The Assembly*: scroll builds the actual 3D hoodie. Torso, ribbed hem, sleeves, cuffs, hood, pocket, drawcords and the K&F mark fly in and join, each with a spec callout. When complete, the stitching appears and the buy action unlocks.
6. **Direction.** Premium-minimal with editorial type (unchanged).
7. **World.** Distinct chapters (kept as is), with one pinned film-like act as the peak.
8. **Assets.** Own assets only: procedural 3D garments and 270 rendered studio photographs. No generated video, no API key, no spend.

## Feeling curve
- Hero: recognition. The wordmark sits behind a real garment.
- Manifesto: tension. A statement, no media.
- **Assembly: wonder** (peak). The parts converge into one object.
- Editorial: calm confidence. Images only.

## The peak
"I scrolled and the hoodie built itself, piece by piece, out of its actual parts." Lives in the Assembly act.
